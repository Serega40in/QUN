# QUN Node — запуск на устройствах

Это ранний локальный тестовый запуск, а не публичное присоединение к QUN-сети. Вознаграждений QUN пока нет.

## Windows 10/11

1. Клонируйте репозиторий QUN или скачайте его с GitHub.
2. Откройте PowerShell в каталоге репозитория.
3. Выполните:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\services\qun-node\scripts\install-windows.ps1
```

Установщик запросит подтверждение, при необходимости предложит установить Node.js LTS и Git через winget, проверит тесты и запустит узел. Панель: http://127.0.0.1:8787/. Окно терминала нужно оставить открытым. Это пока не подписанный MSI и не служба Windows.

## Android

1. Установите Termux из доверенного источника.
2. Откройте Termux и выполните:

```bash
pkg update
pkg install -y curl
curl -fsSL https://raw.githubusercontent.com/Serega40in/QUN/main/services/qun-node/scripts/install-android-termux.sh -o install-qun-node.sh
bash install-qun-node.sh
```

Перед запуском удалённого скрипта можно открыть его исходный код на GitHub и проверить содержимое. Скрипт запускается внутри Termux. Панель: http://127.0.0.1:8787/ на самом телефоне. Android может останавливать фоновые процессы; полноценный APK пока не создан.

## Безопасность

- Узел слушает только 127.0.0.1; не меняйте адрес на 0.0.0.0.
- Не открывайте порт 8787 на роутере и не публикуйте его в интернете.
- Не вводите секреты, пароли или реальные пользовательские данные.
- Установщик не включает автозапуск, публичную регистрацию, кошелёк или выплаты.
- Перед широким распространением нужны подписанные релизы, безопасное подключение к сети и аудит.
