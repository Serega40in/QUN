# Благотворительный фонд «КЮН» — комплект для подготовки регистрации

**Статус: рабочие проекты, не готовый к подписанию юридический комплект.** Перед подачей обязательна проверка актуальных требований Минюста и заполнение отмеченных полей.

## Принцип минимализма
Не добавляем лишние положения и внутренние регламенты. Не публикуем паспорта, домашние адреса, подписи, банковские реквизиты и другие персональные данные в открытом репозитории.

## Что пока не готово
1. Адрес места нахождения в Санкт-Петербурге.
2. Подтверждение согласия обоих учредителей.
3. Состав высшего коллегиального органа управления.
4. Состав попечительского совета.
5. Подтверждение согласия Юрия Николаевича Косаринцева стать директором и определение срока полномочий.
6. Заполнение действующего регистрационного заявления Минюста.
