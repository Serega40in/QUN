# КЮН / QUN

Единая цифровая экосистема: мессенджер, платформа и будущие сервисы КЮН.

## Проекты

- **Веб-мессенджер:** адаптивный интерфейс для компьютеров и телефонов — `docs/index.html`.
- **Android:** Kotlin + Jetpack Compose.
- **Backend:** Supabase Auth + PostgreSQL + Row Level Security.
- **Сборка Android:** GitHub Actions workflow `.github/workflows/build-apk.yml`.
- **Публикация веб-версии:** `.github/workflows/deploy-web.yml`.

## Возможности веб-MVP

- вход по номеру телефона через SMS OTP Supabase Auth;
- профиль, имя и уникальный username;
- поиск пользователей по имени и username;
- создание личного диалога;
- отправка и получение сообщений;
- обновление сообщений и списка диалогов с периодическим опросом;
- адаптивный интерфейс для мобильного и настольного браузера.

Веб-версия использует тот же Supabase-проект и те же таблицы, что и Android-приложение. Для неё используется только публичный publishable key; service-role ключ не передаётся в браузер.

## Публикация веб-версии

1. Откройте **Settings → Pages** в репозитории GitHub.
2. В разделе **Build and deployment** установите **Source: GitHub Actions**.
3. После этого workflow запустится при изменениях в `docs/` или вручную через **Actions → Deploy QUN Web → Run workflow**.
4. Адрес сайта появится в успешном запуске workflow и в настройках Pages. Обычно это `https://serega40in.github.io/QUN/`.

## Важно перед публичным запуском

- SMS OTP заработает только после корректной настройки SMS-провайдера в Supabase Auth. Ранее SMS Aero отклонял настроенное имя отправителя; нужно указать имя отправителя, одобренное провайдером.
- Функция `qun-test-login` — тестовый механизм Android-прототипа, а не безопасная публичная авторизация. Не используйте её для публичного сайта или реальных пользовательских аккаунтов; Android-клиент следует перевести на подтверждаемую авторизацию до публичного запуска.
- Перед запуском необходимо протестировать регистрацию двух отдельных пользователей, создание диалога, отправку сообщений и изоляцию данных между аккаунтами.
- Не размещайте секретные ключи Supabase в HTML, JavaScript или GitHub.

**QUN Messenger → QUN Platform → QUN MAP → QUN Wallet → QUN AI → QUN Coin**

Сейчас приоритет — стабильная авторизация, безопасные профили и надёжные личные сообщения. Фото, файлы, голосовые сообщения, push-уведомления, группы и криптовалютные функции добавляются отдельными этапами.
