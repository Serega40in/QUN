# КЮН / QUN

Единая цифровая экосистема: мессенджер, платформа и будущие сервисы КЮН.

## Проекты

- **Веб-мессенджер:** адаптивный интерфейс — `docs/index.html`.
- **Android:** Kotlin + Jetpack Compose.
- **Backend:** Supabase Auth + PostgreSQL + Row Level Security.
- **Сборка Android:** GitHub Actions workflow `.github/workflows/build-apk.yml`.
- **Публикация веб-версии:** `.github/workflows/deploy-web.yml`.

## Возможности веб-MVP

- регистрация по username и паролю;
- вход по username или привязанному телефону и паролю;
- одноразовый перенос некоторых старых тестовых аккаунтов без SMS;
- профили, поиск пользователей по имени и @username;
- создание личных диалогов и отправка сообщений;
- обновление переписки и списка диалогов с периодическим опросом;
- адаптивный интерфейс для компьютера и телефона.

Веб-клиент использует общий Supabase-проект и те же таблицы сообщений, профилей и диалогов, что и остальная платформа. В браузере используется только публичный publishable key; service-role ключ хранится на серверной стороне.

## Публикация веб-версии

GitHub Actions автоматически включает GitHub Pages и разворачивает содержимое папки `docs/` при изменениях сайта. Адрес: `https://serega40in.github.io/QUN/`.

Workflow: [Deploy QUN Web](https://github.com/Serega40in/QUN/actions/workflows/deploy-web.yml).

## Текущие ограничения

- SMS-вход отключён по решению проекта. Номер телефона можно привязать как альтернативный логин, но без SMS он не подтверждает владение номером.
- Старый тестовый endpoint входа отключён, поскольку позволял получать доступ к аккаунту по известному номеру без настоящего пароля.
- Старые аккаунты, созданные через тестовый вход, необходимо активировать через персональный одноразовый код переноса. Новый аккаунт с уже занятым логином создать нельзя.
- Android-клиент ещё использует старый тестовый метод входа и должен быть обновлён под `qun-auth` перед следующим использованием. Для проверки нового веб-MVP используйте браузер.
- Перед публичным запуском нужно дополнительно проверить регистрацию двух новых пользователей, сообщения в обе стороны и изоляцию данных; также добавить ограничение частоты регистраций и восстановление забытого пароля.
