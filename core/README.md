# QUN Core

**QUN Core — собственный блокчейн QUN.** Это отдельный протокол и код узла, а не токен, выпущенный в TON или другой существующей сети.

## Текущий этап

Начальная инженерная база: Rust crate, модели блока/транзакции, хеширование и проверка целостности цепочки. На этом этапе это локальный прототип; он не является готовой mainnet и не должен хранить реальные средства.

## Принципы

- **Свой протокол:** правила блока, транзакций, консенсуса и сетевого обмена определяются проектом QUN.
- **Детерминированная проверка:** узел проверяет связи блоков и содержимое.
- **Безопасность прежде запуска:** криптографические подписи, защита от повторного воспроизведения, ограничения ресурсов, аудит и тестирование должны быть реализованы до обращения с реальными активами.
- **Открытая разработка:** спецификация и тесты хранятся в репозитории.

## Этапы

1. Локальная цепочка и тесты хешей/целостности.
2. Формат транзакции, подписи Ed25519 и проверка nonce/балансов.
3. Хранилище состояния и восстановление узла после перезапуска.
4. Сетевой протокол peer-to-peer и синхронизация.
5. Консенсус и защита от реорганизаций/двойной траты.
6. Devnet, наблюдаемость, fuzz/property tests и независимый аудит.
7. Testnet с публичной спецификацией; только после аудита — отдельное решение о mainnet.

## Локальный запуск

Требуется стабильный Rust toolchain:

```sh
cd core
cargo test
cargo run
```

Сейчас запуск демонстрирует локальную цепочку и проверку связности. Не подключайте реальные средства и не используйте этот код как production-кошелёк.

## Структура

- `src/lib.rs` — примитивы цепочки и валидация.
- `src/main.rs` — локальная демонстрация.
- `Cargo.toml` — зависимости и конфигурация crate.
