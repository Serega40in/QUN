# MASTER BRIEF — generate QUN Omnii Sticker Pack 01

Ты — production-artist и технический координатор стикерпака. Твоя задача — создать готовый к ручной модерации первый оригинальный набор QUN.

## Источники
Внимательно прочитай:
1. docs/stickers/README.md — визуальный стандарт, технические требования, этапы.
2. docs/stickers/PROMPTS_OMNII_01.md — Character lock, Composition lock, negative prompt и 24 точных задания.

Не меняй персонажа и художественный стандарт без отдельного согласования.

## Производственный план

**Этап A — эталон**
- Создай ровно 4 варианта нейтрального Omnii по разделу D файла PROMPTS_OMNII_01.md.
- Покажи четыре варианта на отдельном листе предпросмотра, но сохрани каждый вариант отдельным файлом.
- Сделай выбор одного изображения как омни-reference.png. Не переходи к финальному паку до того, как эталон будет выбран человеком.

**Этап B — контрольный тест**
- На базе утверждённого эталона создай по 3 отдельных варианта для сюжетов 01, 06 и 09.
- Используй один и тот же reference image и один и тот же визуальный стиль. Если лицо, форма меха или пропорции меняются, останови серию и исправь reference workflow.

**Этап C — полный набор**
- Создай по 3 варианта для каждого из 24 сюжетов.
- Каждый вариант — отдельное квадратное изображение, не contact sheet.
- Отбирай один лучший результат для каждого сюжета.
- Финальный набор должен содержать ровно 24 стикера, названия файлов и emoji из PROMPTS_OMNII_01.md.

## Важные требования
- Один и тот же персонаж на всех картинках; сохраняй форму глаз, оттенок, мех и пропорции.
- Один персонаж в одном файле. Не добавляй слова и текст внутри изображений.
- Вся фигура и реквизит остаются внутри кадра с безопасным отступом.
- Не использовать чужих персонажей, логотипы, водяные знаки или образы из защищённых франшиз.
- Прозрачность должна быть настоящей alpha transparency. Шахматка в изображении не является прозрачностью.
- Если модель не умеет прозрачность, применяй чистый равномерный фон #FF00FF и удали его отдельным инструментом, вручную проверь края.
- Не заявляй, что картинка прошла проверку, пока её действительно не просмотрели.
- Не заменяй неудачные изображения случайными вариантами и не подменяй отсутствующие файлы.
- Соблюдай лицензию модели и инструмента генерации. Записывай их названия и версии.

## Форматы выдачи
Для каждого из 24 сюжетов:
- исходный файл высокого качества PNG;
- экспортный файл PNG/WebP с прозрачностью, одна сторона ровно 512 px, другая не больше 512 px;
- один emoji;
- короткое имя файла, например 01-hello.webp;
- статус QA: ACCEPT, REGENERATE или HUMAN REVIEW.

В финале создай:
- папку source/ с отобранными исходниками;
- папку telegram/ с 24 экспортными файлами;
- manifest.json с ID qun_omnii_01, названием, версией, автором, лицензией, инструментом генерации, файлами и emoji;
- preview.png — лист предпросмотра всего набора;
- QA_REPORT.md — краткая проверка каждого из 24 файлов и список замечаний.

Не публикуй набор самостоятельно. Передай ZIP/папки и QA_REPORT человеку для проверки и утверждения. Публикация в QUN и Telegram — отдельный согласованный шаг.

## Если у тебя нет доступа к генерации изображений
Не имитируй готовые результаты. Подготовь рабочий workflow, назови модель и зависимости, перечисли точные шаги запуска и остановись до реальной генерации.
