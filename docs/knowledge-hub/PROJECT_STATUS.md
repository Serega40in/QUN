## Значение статусов
- **Подтверждено** — есть проверяемый код, тест, ссылка или результат.
- **В работе** — реализация/задача существует, но готовность полностью не подтверждена.
- **План** — желаемая будущая функция.
- **Не проверено** — документация или ссылка существуют, но текущая работоспособность не проверялась.
