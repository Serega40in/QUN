# QUN Prompt Library — изображения
Версия 0.1 · Адаптируй шаблоны под конкретную модель

## Правило
Определи продукт и используй его реальные референсы. Общая палитра QUN — направление, а не повод добавлять синий, изумрудный и золото в каждую картинку. Для консистентности прикладывай утверждённые изображения как reference assets, если инструмент это поддерживает.

## Универсальный визуал
> Создай высококачественный визуальный материал для [продукт QUN] с назначением [контекст]. Следуй QUN Visual Bible и приложенным референсам. Сохраняй ясную композицию, узнаваемую форму, продуманные материалы и освещение. Цвета и логотипы воспроизводи по референсам, не угадывай отсутствующие параметры. Главный объект: [объект]. Идея: [идея]. Окружение: [среда]. Композиция: [ракурс, фокус, свободное пространство]. Формат: [соотношение сторон, разрешение, место использования].

## Персонаж / 3D-мультипликация
> Создай оригинального персонажа для [игра/история/продукт]. Стиль — цельная высококачественная стилизованная 3D-анимация с ясным силуэтом, выразительной мимикой, приятными материалами и профессиональным светом. Сохраняй дизайн по приложенному character reference: форма, пропорции, цвета, одежда и отличительные детали неизменны. Покажи [поза/эмоция/действие], камера [ракурс], фон [описание]. Не добавляй случайные надписи, лишние конечности, дубли объектов или артефакты. Не применяй этот стиль к продукту, для которого он не выбран.

## Продуктовая иллюстрация
> Создай чистую продуктовую иллюстрацию для [QUN Market/Publisher/другое]. Продукт — главный фокус; фон поддерживает, но не перетягивает внимание. Оставь [зона] свободной под текст, если требуется. Не генерируй нечитаемые надписи — оставь место для вёрстки. Формат [aspect ratio], использование [web/mobile/social].

## UI-концепт
> Создай концепт интерфейса для [экран продукта QUN]. Приоритеты: понятная иерархия, мобильная адаптивность, доступность, удобные области нажатия, реальные сценарии. Не выдумывай функции вне описания. Считай изображение концептом, а не production UI: код и состояния проверяются отдельно.

## Негативные ограничения
Используй только если генератор поддерживает negative prompt; адаптируй синтаксис: inconsistent character design, malformed anatomy, extra limbs, duplicated objects, random text, fake logos, unreadable typography, cluttered composition, oversaturated glow, harsh bloom, inconsistent lighting, unintended photorealism, style mixing.

## Чек-лист
- Соответствует ли результат конкретному продукту и референсам?
- Сохранены ли персонажи, объекты и пропорции?
- Не появились ли выдуманные логотипы и надписи?
- Читается ли композиция в целевом размере?
- Соответствуют ли цвета утверждённым исходникам?
- Сохранены ли промпт, модель, параметры и дата для повторяемости?
