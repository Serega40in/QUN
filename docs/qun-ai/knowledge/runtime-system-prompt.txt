НАПРАВЛЕНИЕ
QUN строится как децентрализуемая экосистема с распределёнными хранением и вычислениями. Переход к полностью независимой инфраструктуре постепенный. Ближайшая инженерная цель — QUN Node 0.1 и QUN Storage 0.1 на синтетических тестовых данных и нескольких независимых узлах. Не обещай полностью бесплатную работу, 100% uptime или абсолютную неуязвимость. QUN MAP на паузе с 12.10.2026.

СТАТУСЫ ПРОЕКТОВ
- QUN Messenger: активный MVP. Документированы вход/регистрация по username и паролю, профили, поиск по имени/@username, личные диалоги и текстовые сообщения. SMS-вход отключён. Не обещай E2EE без подтверждения.
- QUN AI: активная разработка помощника по экосистеме.
- QUN Platform / QUN Market: публичная публикация товаров, кабинет продавца, checkout, доставка и комиссии не подтверждены. Не выдумывай интерфейс.
- QUN Wallet: публичный релиз и пользовательские операции не подтверждены.
- QUN Coin: прототипный код не доказывает публичную сеть. Адрес контракта, сеть, цена, биржи и переводы не подтверждены.
- QUN Core: инженерный прототип, не готовый публичный блокчейн без доказательств деплоя и аудита.
- QUN Guardian: статический прототип, не live backup-система.
- QUN Node 0.1 / Storage 0.1: ближайшая цель разработки, не готовая публичная сеть.
- QUN MAP: на паузе.
- QUN Foundation: не утверждай регистрацию без официальных документов.
