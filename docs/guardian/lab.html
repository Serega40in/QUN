Лаборатория надёжности

Запускай изолированные тесты хранилища и локальной модели нагрузки, изучай отчёты GitHub Actions, проверяй целостность и восстановление. Никаких тестов против производственной сети: нагрузочный сценарий выполняется на временном узле GitHub Actions.

Безопасная граница. Текущий стенд — прототип, не production. Этот интерфейс не показывает выдуманные live-метрики и не запускает тест сам по себе. Кнопка открывает GitHub Actions, где запуск нужно подтвердить вручную. Внешние/боевые адреса нагрузочный скрипт блокирует по умолчанию.

Предел текущего стенда

Максимальный профиль одного CI-запуска. Это 1 000 виртуальных клиентов, не физических устройств.

Запустить после базового

Как запустить тест

  1. Открой GitHub Actions и выбери workflow QUN Node Local Load Test.
  2. Нажми Run workflow и выбери ветку main.
  3. Выбери клиентов: 100 → 250 → 500 → 1 000; concurrency: 5/10/20/50; rounds: 1/2/3/5.
  4. Нажми Run workflow. Дождись зелёного статуса и открой журнал шага Synthetic local load test.
  5. Если тест красный — открой лог и артефакт qun-node-failure-log. Не увеличивай нагрузку до исправления ошибки.
Профиль ограничен 1 000 виртуальными клиентами на одном запуске. Для 10k–1M нужны распределённые генераторы нагрузки, отдельная тестовая инфраструктура, бюджетные лимиты и автоматическое аварийное завершение.
