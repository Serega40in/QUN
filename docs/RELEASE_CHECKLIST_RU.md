## 1. Технические блокеры перед публичным релизом
- [ ] Обновить Android-клиент: убрать устаревший тестовый метод входа; подключить актуальный `qun-auth` / Supabase Auth flow.
- [ ] Проверить регистрацию и вход двух новых пользователей на двух отдельных устройствах.
- [ ] Проверить отправку/получение сообщений в обе стороны, список диалогов, непрочитанные сообщения, выход и повторный вход.
- [ ] Проверить RLS: пользователь не может читать чужие профили/диалоги/сообщения без разрешения.
- [ ] Проверить восстановление доступа, обработку ошибок сети, повторные запросы и ограничение частоты регистрации.
- [ ] Проверить, что в release-сборке нет тестовых аккаунтов, секретов, service-role ключей, debug-настроек и тестовых URL.
- [ ] Проверить разрешения Android manifest и соответствие фактическому использованию данных.
- [ ] Проверить совместимость с целевыми Android-устройствами и отсутствие падений.

## 2. Подпись и сборки
- Application ID: `com.qun.messenger`
- Текущая версия в проекте: `0.13.0` (versionCode 14; проверить перед релизом).
- Google Play: загрузить подписанный `.aab`; включить Play App Signing при создании релиза.
- RuStore: допускает подписанные APK и AAB; для AAB подпись настраивается отдельно в консоли RuStore.
- Huawei / Samsung: проверить актуальные требования к формату пакета и подписи в соответствующей консоли.
- Хранить upload/release keystore и пароли в менеджере секретов; не добавлять их в Git.
- Никогда не менять ключ подписи для уже опубликованного package ID без заранее проверенного плана миграции.

## 4. Создание аккаунтов и публикация
1. Google Play Console: зарегистрироваться, оплатить разовый сбор, пройти верификацию. Для новых личных аккаунтов проверить текущие требования к закрытому тестированию и проверке устройства.
2. RuStore Console: создать аккаунт через VK ID; добавить приложение, заполнить карточку, загрузить подписанную сборку и отправить на модерацию.
3. Huawei AppGallery Connect: зарегистрировать и верифицировать Huawei Developer ID, создать приложение, добавить карточку и политику конфиденциальности, загрузить пакет.
4. Samsung Seller Portal: зарегистрироваться, добавить приложение, указать тестовые данные для модерации при необходимости и отправить на проверку.
5. Не считать приложение опубликованным до статуса Approved/Published и проверки публичной страницы/установки.
