# QUN Masterpiece (MVP)

Открытая творческая галерея, продолжающая QUN Animation Studio.

## Что реализовано в интерфейсе
- Публичная лента публикаций из `public.social_posts`.
- Фильтры «Все работы / Арты / Видео».
- Вход и регистрация через Supabase Auth.
- Публикация текста с HTTPS-ссылкой на изображение или видео.
- Отметки «нравится» и комментарии через существующие `social_likes` и `social_comments`.
- Творческий помощник через Edge Function `qun-gigachat-director`.
- Ссылка назад в QUN Studio.

## Бесплатная инфраструктура
Страница — статический GitHub Pages. Она использует уже существующий Supabase проект QUN. Генерации медиа не запускаются автоматически, а платные ресурсы не подключаются.

## Включение ГигаЧата
1. В Supabase Dashboard → Edge Functions → Secrets добавьте `GIGACHAT_CREDENTIALS` (Authorization Key) и при необходимости `GIGACHAT_SCOPE` (по умолчанию `GIGACHAT_API_PERS`).
2. Функция `qun-gigachat-director` не делает запрос к GigaChat, пока ключ отсутствует.
3. Первый реальный запрос расходует квоту GigaChat API. Перед публичным включением проверьте актуальный лимит/тариф и настройте лимиты использования. Секрет не должен попадать в HTML или Git.

## Ограничения MVP
- Медиа указывается по HTTPS-ссылке; импорт прямо из библиотеки студии и автоматическая загрузка медиа будут следующим этапом.
- Публичная публикация зависит от уже действующих RLS-политик Supabase.
- Вход использует текущий QUN Supabase Auth.
- Реальная проверка API ГигаЧата невозможна, пока секрет не задан.
