# QUN Wear — production masters

Первая система одежды QUN на базе исходников из `docs/wear`.

## Концепция: «Живой код QUN»

Буква **K** сохранена как криптографический знак и переосмыслена как дерево: вертикаль — ствол, диагонали — ветви, основание — корни. Центральная звезда — точка соединения. Орбита, ДНК, горы и река объединяют технологию и живую природу.

## Комплектация

- `QUN-WEAR-CHEST-EMBROIDERY.svg` — нагрудный знак, 60 × 70 мм.
- `QUN-WEAR-BACK-EMBROIDERY.svg` — широкая версия для вышивки на спине, 320 × 235 мм.
- `QUN-WEAR-BACK-PRINT-DARK.svg` — детальная печатная версия для тёмной ткани, 320 × 255 мм.
- `QUN-WEAR-BACK-PRINT-LIGHT.svg` — версия для светлой ткани, 320 × 255 мм.

Все файлы — векторные SVG с прозрачным фоном. Текст в исходниках оставлен редактируемым; перед производством его следует перевести в кривые, если типография не использует шрифты Noto Serif и Inter.

## Палитра

- Deep Navy — `#0B1E3B`
- Emerald — `#0D806A`
- Deep Teal — `#117C70`
- Warm Gold — `#C8A45D`
- Warm Ivory — `#F1E7D2`

Цвета ориентировочные. Для вышивки мастерская подбирает ближайшие нити по своей карте.

## Производственные рекомендации

- Грудь: ориентир 55–60 мм по ширине; не уменьшать без тестового отшива.
- Спина: ориентир 280–320 мм по ширине.
- Перед тиражом сделать пробный отшив на той же ткани, проверить плотность настила, стягивание и компенсацию.
- SVG — это дизайн-мастера, **не** готовые машинные файлы DST/PES. Программу стежков должен подготовить дигитайзер под конкретную ткань, нитки и машину.
- Печатные версии перед тиражом проверить цветопробой на выбранной ткани.

## Статус

Первая концепция для примерки и тестового образца. Финальную плотность стежков и размеры нужно подтвердить с производством.
