# QUN Pictures — Production Checklist
## Phase 1 — Creative lock
- [ ] Утвердить рабочее название QUN Pictures / QUN Pixar (перед коммерческим использованием проверить название и товарные знаки).
- [ ] Утвердить персонажа Кью по силуэту и character bible.
- [ ] Создать чистый белый turnaround и expression sheet.
- [ ] Зафиксировать цветовую палитру и правила постоянства модели.
- [ ] Утвердить точный перечень реально работающих продуктов и тех, что пока в разработке.

## Phase 2 — Music
- [ ] Сгенерировать 3–6 вариантов трека в Suno.
- [ ] Выбрать вокальную подачу и проверить произношение Q-U-N.
- [ ] Сохранить instrumental и vocal master.
- [ ] Утвердить длительность и монтажные маркеры.
- [ ] Проверить коммерческие права согласно актуальному тарифу и условиям сервиса.

## Phase 3 — Visual development
- [ ] Подготовить 6 ключевых style frames.
- [ ] Сгенерировать storyboard thumbnails.
- [ ] Проверить силуэт и лицо Кью на всех планах.
- [ ] Создать отдельные product-metaphor кадры: Messenger, AI, Social/Market, Node/Storage, Foundation.
- [ ] Не показывать концептуальные продукты как уже запущенные сервисы.

## Phase 4 — Production
- [ ] Генерировать сцены короткими отрезками.
- [ ] Сохранять один и тот же character reference.
- [ ] Отобрать лучший дубль для каждой сцены.
- [ ] Сделать монтаж под вокальные и инструментальные акценты.
- [ ] Добавить sound design: sparkle, soft whoosh, warm low-frequency impact, subtle chimes.
- [ ] Добавить логотип и титры в редакторе, не полагаться на текст генератора.

## Phase 5 — Delivery
- [ ] Master 3840×2160, 16:9.
- [ ] Social 1920×1080.
- [ ] Vertical 1080×1920.
- [ ] Square 1080×1080.
- [ ] Субтитры RU и EN.
- [ ] Проверить артефакты, flicker, continuity, аудио-пики и мобильную читаемость.
- [ ] Архивировать prompts, references, audio masters, project files и final exports.
