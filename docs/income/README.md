# S40in AI Income

Личная панель управления заказами S40in AI Studio, финансами, задачами и целью на оплату AI-инструментов.

Открыть приложение: https://serega40in.github.io/QUN/income/

Вход: существующий QUN ID. Используется Edge Function qun-auth в Supabase QUN.

Данные хранятся в отдельных таблицах ai_income_* с включённой Row Level Security и политиками владения по auth.uid(). Не хранить клиентские пароли, seed-фразы и приватные криптоключи в приложении.

Резерв в интерфейсе — это учётная запись в USD. Это не автоматический перевод в Telegram Wallet и не криптокошелёк.
