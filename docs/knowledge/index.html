QUN · Universal Context Loader

Ты подключаешься к проекту QUN. Сначала прочитай AI_START_HERE.md:
https://github.com/Serega40in/QUN/blob/main/docs/knowledge-hub/AI_START_HERE.md

Центральная страница знаний:
https://serega40in.github.io/QUN/knowledge/

Изучи только разделы, относящиеся к задаче, затем проверь актуальные исходники и статус. Различай подтверждённые факты, планы и предположения. Соблюдай Visual Bible. Не выдумывай отсутствующие параметры и не заявляй о действиях без проверки. Если не можешь открыть ссылку, попроси пользователя загрузить нужный файл. В конце укажи изученный контекст, изменения и следующие шаги.

Как подключить новую ИИ

01 · Передайте ссылкуОтправьте Knowledge Hub вместе со стартовым промптом.

04 · Сохраните результатОбновите документы и статус в GitHub для следующей ИИ.
