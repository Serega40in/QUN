1. Создать одноразовый код

Код действует 15 минут, используется один раз и привязывает будущий Linux GPU-узел к текущему QUN ID.

Не публикуй код в GitHub, чатах или скриншотах. Вводи его только в локальной консоли своего сервера, когда будешь готов зарегистрировать GPU-узел.

Windows CPU — свой бесплатный узел для монтажа

Для личного компьютера Windows без мощной видеокарты. Он не генерирует AI-видео, зато сам склеивает готовые сцены, обрезает музыку, пережимает результат и сохраняет фильм в твою QUN Library. ComfyUI и скачивание AI-моделей не нужны.

Нужны Python 3, Git, FFmpeg и ffprobe. На твоём компьютере этот режим реалистичнее, чем запуск тяжёлой видеомодели на Intel HD 505.

Проверь команды в PowerShell: python --version, git --version, ffmpeg -version, ffprobe -version. При отсутствии Git или FFmpeg их можно установить через WinGet:

winget install -e --id Git.Git
winget install -e --id Gyan.FFmpeg

После установки открой новое окно PowerShell и повтори проверку версий. WinGet-пакеты Git for Windows и FFmpeg доступны для Windows 10+. Git for Windows · FFmpeg builds.

git clone --depth 1 https://github.com/Serega40in/QUN.git "$HOME\QUN"
cd "$HOME\QUN\docs\studio"
$env:QUN_SUPABASE_PUBLISHABLE_KEY = "sb_publishable_aCUwbGYj_kUU8nVUu1kWmQ_-d-8fp8L"
$env:QUN_NODE_PLATFORM = "windows-cpu"
python .\register_gpu_worker.py
$env:QUN_FFMPEG_PATH = "ffmpeg"
$env:QUN_FFPROBE_PATH = "ffprobe"
$env:QUN_COMFYUI_OUTPUT_DIR = "$HOME\QUN-Render-Output"
python .\comfyui_worker.py

Сначала нажми «Создать код подключения» выше. Код вводится локально при регистрации. Секрет узла останется в защищённом файле на компьютере; не отправляй его в чат или GitHub. После запуска узел появится в списке. В QUN Director он будет использоваться только для финального монтажа собственных сцен.

2. Запустить регистрацию на Linux-сервере

После клонирования QUN репозитория или загрузки файла регистрации выполни команды ниже. Понадобится Python 3 и публичный ключ Supabase (он не является секретом).

git clone --depth 1 https://github.com/Serega40in/QUN.git ~/qun-repo
cd ~/qun-repo/docs/studio
export QUN_SUPABASE_PUBLISHABLE_KEY="sb_publishable_aCUwbGYj_kUU8nVUu1kWmQ_-d-8fp8L"
python3 register_gpu_worker.py

Файл регистрации спросит название узла и одноразовый код. Индивидуальный секрет сохранится локально в ~/.config/qun/render-node.json с правами 600. Не отправляй этот файл никому.
