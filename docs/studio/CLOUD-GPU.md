- В таблице `qun_nodes` зарегистрированы четыре узла, но последние heartbeat не свежие: `q1` последний раз отмечался 2026-10-20, `QUN Node` — 2026-10-27, один `QUN Phone` — 2026-10-24.

## Рекомендуемый путь: бесплатная проверка без риска списаний

### Вариант A — Comfy Cloud Free

Официальная страница: https://comfy.org/cloud  
Тарифы: https://comfy.org/pricing/

Comfy Cloud объявил 400 бесплатных кредитов в месяц без привязки карты. Это хороший способ проверить качество и подобрать видео-workflow. Бесплатные кредиты ограничены и не являются бесконечным GPU.

Важно: сначала проверить наличие API-доступа, доступного на бесплатном тарифе, и условия автоматизированного запуска. Нельзя хранить пользовательский токен в GitHub Pages или браузерном коде. Если API для Free недоступен, используем Comfy Cloud как ручной тестовый этап, а интеграцию делаем через провайдера с поддерживаемым API и бесплатной квотой.

### Вариант B — бесплатные notebook GPU

Kaggle и Google Colab полезны для экспериментов с workflow, но это не постоянный сервер. У Google Colab бесплатный уровень прямо ограничивает сценарии удалённого управления, web-UI и distributed workers. Поэтому не используем бесплатный Colab как постоянно работающий публичный GPU-бэкенд QUN.

## Архитектура интеграции

1. GitHub Pages отправляет задание в авторизованный QUN API.
2. Supabase сохраняет prompt и статус задания; секреты провайдера хранятся только на сервере.
3. Worker/adapter отправляет задание выбранному GPU API.
4. Результат загружается в QUN Storage/Supabase Storage, а не выдаётся ссылкой на временный внутренний адрес GPU.
5. UI показывает прогресс, результат, ошибки, остаток бесплатной квоты и понятное сообщение, когда квота исчерпана.

## Защита от случайных расходов

- Не создавать ресурсы у платных провайдеров и не добавлять платёжные ключи без явного согласования.
- По умолчанию отключить auto-upgrade и любые платные fallback-маршруты.
- Ограничивать длительность и размер заданий, число одновременных задач и хранение результатов.
- Не отправлять секреты в браузер, публичный репозиторий, URL-параметры или логи.

## Критерий готовности

Первый успешный end-to-end тест: отправить тестовое задание со страницы QUN Studio, увидеть его в очереди, получить результат от GPU, сохранить результат в постоянное хранилище и открыть его с телефона без прямого доступа к адресу ComfyUI. Пока такой тест не выполнен, студия считается подготовленной, но не полностью подключённой к облачному GPU.
