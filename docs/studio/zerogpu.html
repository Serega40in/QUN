Создавай видео прямо в QUN Studio

Мы проверили подход: видео успешно создаётся в оригинальном Hugging Face Space, а прямой вызов API с GitHub Pages падает с TypeError: Failed to fetch. Поэтому основной режим теперь использует официальный встроенный интерфейс Space, а не ненадёжный браузерный API-вызов. Загрузи изображение, задай движение, запусти генерацию и скачай результат в интерфейсе ниже.

Генерация выполняется на стороне Hugging Face. Бесплатная GPU-квота и очередь ограничены. QUN не включает платные услуги и не запрашивает твой токен. Не загружай приватные изображения в сторонний сервис.
