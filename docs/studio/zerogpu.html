Этот инструмент подключается к публичному Hugging Face Space Wan 2.2 Image-to-Video. Он анимирует загруженную картинку, а не создаёт ролик только из текста. После генерации появятся видеоплеер и отдельная кнопка скачивания.

Лучше описывать движение, камеру, атмосферу и свет. Картинка станет первым кадром.
Токен используется только в памяти этой вкладки и передаётся напрямую Hugging Face. Он не записывается в QUN, GitHub или localStorage. Для большей безопасности используй токен только с правом чтения.
Бесплатная GPU-квота ограничена и очередь может быть занята. Здесь нет платного переключения. Не закрывай вкладку до появления результата. Не загружай приватные изображения в сторонний Space.
