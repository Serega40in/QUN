# QUN Kaggle Render Worker — инструкция

**Статус:** личный тестовый GPU-узел, первая версия — только text-to-image.  
**Ноутбук:** [скачать .ipynb](https://raw.githubusercontent.com/Serega40in/QUN/main/tools/qun-node-worker/kaggle_qun_render_worker.ipynb) · [открыть исходник](https://github.com/Serega40in/QUN/blob/main/tools/qun-node-worker/kaggle_qun_render_worker.ipynb)

## Что делает Worker

QUN Studio → авторизованный QUN Compute → Kaggle Worker → локальный ComfyUI → приватный QUN Storage → QUN Library.

Worker забирает задания сам через исходящий HTTPS. Публичный ComfyUI, Cloudflare Tunnel, ngrok и открытые порты не нужны. Задание и результат остаются привязанными к QUN ID, владельцу узла и его приватной библиотеке.

## Подготовка Kaggle

1. Создай Kaggle Notebook и импортируй скачанный файл `.ipynb`.
2. В Settings включи **Accelerator → GPU** (если выбор доступен, начни с **T4x2**) и **Internet → On**.
3. В Hugging Face открой [Stable Diffusion 1.5](https://huggingface.co/stable-diffusion-v1-5/stable-diffusion-v1-5), прими условия доступа и создай Read token.
4. В Kaggle добавь секрет **HF_TOKEN** со значением этого токена. Не вставляй токен непосредственно в ячейку или репозиторий.
5. Выполняй ячейки сверху вниз. Установка ComfyUI и загрузка checkpoint 4,27 ГБ происходят только в Kaggle-сессии.

## Привязка к QUN ID

1. В другой вкладке открой [QUN Render Node](https://serega40in.github.io/QUN/studio/render-node.html) и войди под тем QUN ID, в чью библиотеку должны попадать результаты.
2. Нажми **Создать код подключения**.
3. В ячейке 5 Kaggle вставь одноразовый код (он действует 15 минут и используется один раз).
4. Worker зарегистрируется как `linux-gpu` и сохранит индивидуальный node token в локальном файле Kaggle с ограниченными правами.

Для повторного использования узла добавь показанные после первой регистрации значения **QUN_NODE_ID** и **QUN_NODE_TOKEN** в Kaggle Secrets. Вывод ячейки с токеном после копирования очисти. Если не сохранять секреты, при новой Kaggle-сессии просто создай новый одноразовый код и зарегистрируй новый Worker.

## Запуск и первый рендер

1. Убедись, что ComfyUI запущен (ячейка 6).
2. Запусти ячейку 7 — она остаётся выполняться и поддерживает heartbeat.
3. В QUN Studio отправь сначала задание **Проверка очереди**.
4. После успешной проверки создай задание типа **Генерация изображения** и используй короткий тестовый prompt.
5. Worker получит задание, создаст PNG 512×512, загрузит файл в приватный bucket `qun-studio-media` и зарегистрирует материал в QUN Library.
6. Открой библиотеку в QUN Studio и проверь, что картинка просматривается и скачивается.
7. Для остановки нажми Interrupt в ячейке 7, затем выполни ячейку 8.

## Что умеет первая версия

- GPU-рендер изображений через ComfyUI + Stable Diffusion 1.5;
- отдельный owner-bound QUN Render Node;
- проверка очереди и heartbeat;
- загрузка PNG в приватное QUN Storage;
- создание карточки результата в QUN Library.

**Пока не поддерживаются** генерация видео, музыки и автоматическая сборка клипа на этом Kaggle Worker. Для них нужны отдельные проверенные workflow и модели. Не отправляй задания `video_generation` и `audio_generation` на эту первую версию.

## Важные ограничения и безопасность

- Kaggle — временная среда, не постоянный сервер. Официальная документация указывает до 12 часов на интерактивную GPU-сессию; доступность GPU и недельная квота зависят от аккаунта и загрузки. После остановки Worker будет offline, задания останутся в очереди. См. [Kaggle Notebooks](https://www.kaggle.com/docs/notebooks) и [объявление о T4x2](https://www.kaggle.com/product-announcements/735239).
- Условия Kaggle ограничивают использование сервисов собственными личными некоммерческими задачами. Этот путь подходит для личного тестирования и собственных творческих экспериментов, но не для коммерческого сервиса, клиентских рендеров или обработки заданий других пользователей. См. [Kaggle Terms](https://www.kaggle.com/terms).
- ComfyUI слушает только `127.0.0.1:8188`. Не меняй адрес на `0.0.0.0`, не открывай порт и не создавай публичный туннель.
- Не коммить `render-node.json`, `QUN_NODE_TOKEN`, `HF_TOKEN` или вывод с секретами.
- Публикация и автоматическая отправка результатов куда-либо не выполняются: результат сохраняется в приватную QUN Library владельца.
- Лицензия модели — CreativeML OpenRAIL-M. Проверь условия модели и права на результат отдельно перед любым коммерческим использованием.
