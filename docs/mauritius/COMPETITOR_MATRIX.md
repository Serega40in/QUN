## Findings so far
1. Local marketplace competition is real and includes more than one product. “Mauritius's first marketplace” is not a defensible QUN claim.
2. Existing marketplaces already combine local listings with seller contact; one already promotes auctions. Differentiation must come from verified user pain, trusted operations, integration or a clearly underserved niche.
3. Mauritius has an official AI solution marketplace, so QUN should map its providers and potential partnership opportunities before creating a competing AI directory.
4. No evidence yet supports launching a new general-purpose messenger as the first product. Messaging network effects make a focused use case important.
5. Crypto is legally and operationally heavier than a typical community or catalogue pilot.
