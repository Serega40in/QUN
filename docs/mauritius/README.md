# QUN Mauritius — local chapter of the global QUN ecosystem

**Status:** discovery, brand review and pilot concept. Market: Republic of Mauritius. Working language: English first, with French and Kreol Morisien localization to be validated.

## Mission
Bring QUN to Mauritius through locally relevant digital products while sharing the international QUN identity, technology foundations, security standards and governance. This local-chapter concept does not itself create a legal entity or grant a financial licence.

## Concept preview
[Open the static landing-page concept](site/index.html). It is a non-production mockup, not a live service. No registration, payment processing, token, or operational marketplace is offered.

## Product map
- QUN Website — local landing page and service directory.
- QUN Messenger — communication and communities.
- QUN Market — local business and product discovery, only with proven differentiation.
- QUN AI — tools for residents, creators and businesses.
- QUN ID — shared identity, subject to privacy/security review.
- QUN Hub / Developer API — open contributions, documentation and integrations.
- QUN Node / Storage / Guardian — later infrastructure pilots after security testing.
- QUN Wallet / token — separate legal and compliance gate; not part of the first MVP.

This is a target map, not a claim that every module is production-ready or locally available.

## Initial research conclusion
Local competitors already cover marketplaces, merchant storefronts, delivery, WhatsApp-based selling, payment integration and AI business tooling. A generic marketplace, new messenger or “catalogue + WhatsApp + AI” product is not sufficiently differentiated based on current desk research. Interview users before selecting a narrow pilot.

## Workstreams
| Workstream | Deliverable |
|---|---|
| Market discovery | Competitor matrix, user segments, verified unmet need |
| Brand and IP | Official mark search, classes, ownership and filing recommendation |
| Legal/compliance | Operating model, privacy, e-commerce, payments and crypto assessment |
| Localization | English draft, French review, Kreol Morisien validation |
| Product architecture | Shared global components vs local configuration |
| Pilot | One measurable, user-tested experiment |
| Launch operations | Support, incident response, moderation and metrics |
