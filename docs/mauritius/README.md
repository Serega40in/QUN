# QUN Mauritius — local chapter of the global QUN ecosystem

Status: discovery and planning. Market: Republic of Mauritius. Working language: English first, with French and Mauritian Creole localization to be validated.

## Mission
Bring QUN to Mauritius through locally relevant, accessible digital products while sharing the international QUN brand, technology foundations, security standards, and governance principles. QUN Mauritius is a local chapter/market initiative, not a disconnected fork. This description does not itself establish a legal entity or grant any financial licence.

## Product map
- QUN Website — local landing page and service directory.
- QUN Messenger — communication and communities.
- QUN Market — local businesses, product discovery, seller-buyer contact.
- QUN AI — AI tools for residents, creators, and businesses.
- QUN ID — shared identity and sign-in, subject to privacy/security review.
- QUN Wallet / token — research only until legal classification, licensing, custody, consumer-protection, tax, and AML/CFT requirements are reviewed.
- QUN Hub / Developer API — open contributions, documentation, integrations.
- QUN Node / Storage / Guardian — later-stage infrastructure pilots after security and operational testing.
- QUN Publisher / Search / Core — future modules based on demand.

This is a target map, not a claim that every module is production-ready or locally available.

## Principles
1. Reuse global QUN code and standards where practical; localize presentation, partnerships, operations and compliance.
2. Verify competitors and customer needs before claiming a market gap.
3. No paid cloud resources, token sale, exchange listing, custody service or financial product without explicit approval and documented legal review.
4. Never promise investment returns or token appreciation.
5. Minimize personal data and assess applicable Mauritius data-protection and cross-border transfer requirements.
6. Record source, date checked and confidence for research claims.
7. Use feature branches and reviewed pull requests.

## Workstreams
| Workstream | Deliverable |
|---|---|
| Market discovery | Competitor matrix, user segments, unmet needs |
| Brand and IP | QUN clearance search, classes, ownership and filing strategy |
| Legal and compliance | Operating model, data protection, e-commerce, payments, crypto assessment |
| Localization | English copy, French review, Kreol Morisien validation |
| Product architecture | Shared global services vs local configuration |
| Pilot | One measurable product experiment |
| Launch operations | Support, incident handling, moderation, partnerships and metrics |
