## Definition of done для v1 testnet
- [ ] Успешная регистрация/вход QUN ID.
- [ ] Каждый пользователь получает собственный wallet.
- [ ] Faucet изолирован по кошельку и доступен один раз.
- [ ] Перевод работает между двумя пользователями и не допускает overspend при конкуренции.
- [ ] Повторный запрос не создаёт двойную операцию.
- [ ] История доступна только участнику соответствующей операции.
- [ ] CI проверяет SQL/клиентские тесты.
- [ ] Все экраны явно обозначают тестовую сеть.
- [ ] Нет функций, создающих впечатление доступности реальных денег.
