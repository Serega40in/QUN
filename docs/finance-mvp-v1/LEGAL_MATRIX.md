# QUN Finance MVP v1 — юридическая матрица

Этот документ — список вопросов для юриста, не юридическое заключение. До выбора одной стартовой страны нельзя достоверно определить применимые лицензии и обязанности.

| Функция | v1 статус | Что проверить до запуска за пределами тестовой среды |
|---|---|---|
| Показ тестовых единиц QUN | Разрешить как demo с явным disclaimer | Не представлять как деньги, депозит, инвестицию или обещание дохода |
| Внутренние тестовые переводы | Разрешить только тестовые балансы | Условия использования, abuse prevention, защита данных |
| Подключение внешнего self-custody кошелька | Отдельный этап, сначала testnet | Конкретная роль оператора по применимому крипторегулированию |
| Отправка on-chain транзакции | Не включать до проверки | Сеть, санкции, AML, обязанности провайдера, consumer disclosures |
| Банковский баланс / IBAN | Выключено | Регулируемый партнёр, договоры, права клиента, safeguarding |
| Пополнение/вывод фиата | Выключено | Платёжная лицензия/агентская модель, KYC/AML, возвраты и жалобы |
| Обмен фиат/крипто | Выключено | Отдельная юридическая квалификация и авторизация |
| Custody чужих криптоактивов | Не реализовывать в MVP | Авторизация, custody controls, segregated assets, audit и страхование при необходимости |
| Карты | Выключено | Эмитент, карточная схема, KYC, PCI scope, dispute process |

## Юрисдикционный план

1. Определить страну учреждения компании, налоговое резидентство, страны целевых клиентов и язык поддержки.
2. Составить список фактических функций и потоков активов.
3. Получить письменную оценку юриста, специализирующегося на fintech/crypto в выбранной стране.
4. Для ЕС отдельно проверить MiCA/CASP и платёжное регулирование применительно к конкретной функции и актуальному переходному режиму.
5. Для международного доступа применять географические ограничения там, где нет разрешённой модели.
6. Согласовать privacy notice, retention, data subject requests, incident reporting и договоры с обработчиками.
7. Не принимать деньги пользователей и не объявлять публичный запуск до завершения проверки.

## Обязательные публичные раскрытия

- QUN Wallet v1 — технический прототип.
- Тестовые QUN не имеют денежной стоимости и не являются вкладом, электронной денежной стоимостью или инвестицией.
- Текущая версия не предоставляет банковские счета, карты, обмен или вывод.
- Риски и обязанности при подключении внешнего блокчейн-кошелька должны быть показаны перед включением соответствующих функций.
