# QUN News: серия публикаций о QUN Desktop Agent

Статус: редакционный пакет для подготовки и публикации. Публиковать после проверки актуальной версии проекта и ссылок. Это часть существующего потока QUN News; отдельная ежедневная автоматизация не создаётся.

## Публикация 1 — Знакомство

**Заголовок:** QUN Desktop Agent: ИИ и браузер в одном рабочем пространстве

Мы развиваем QUN Desktop Agent — открытый экспериментальный проект, который объединяет ИИ-чат и настоящий браузер в одном настольном окне. Идея проста: не прыгать между десятком инструментов, а разбирать страницы, задавать вопросы модели и сохранять результаты в одном месте.

Уже есть встроенный браузер, история чатов, подключение совместимых моделей, локальные заметки и экспорт ответов в файлы. Это ранний MVP: мы честно показываем, что уже работает, а что ещё нужно довести до надёжного результата.

Исходный код и развитие: https://github.com/Serega40in/QUN/tree/main/apps/qun-desktop-agent

## Публикация 2 — Как попробовать

**Заголовок:** QUN Desktop Agent: первый запуск за несколько шагов

Для запуска из исходников нужны Node.js 20+, папка `apps/qun-desktop-agent`, команда `npm install` и затем `npm start`. После запуска откройте «Модели и API», настройте совместимый HTTPS endpoint и модель. Ключ нужен только если выбранный провайдер его требует.

Важно: бесплатность зависит от условий провайдера, а приватные данные не стоит отправлять внешней модели без необходимости. Подробный туториал: https://github.com/Serega40in/QUN/blob/main/apps/qun-desktop-agent/TUTORIAL_RU.md

## Публикация 3 — Разбор сайта с помощью ИИ

**Заголовок:** Практика: попросите ИИ объяснить открытую веб-страницу

Откройте страницу во встроенном браузере, затем в чате попросите модель кратко изложить содержание, найти основные условия или составить список вопросов. QUN Desktop Agent передаёт ограниченный текст текущей страницы в контекст запроса. Результат нужно проверять: модель может ошибаться, а текст сайта не является доверенной инструкцией.

## Публикация 4 — Сохранение результата

**Заголовок:** Из чата в файл: сохраняем результат работы

Ответ QUN Desktop Agent можно сохранить по кнопке «Сохранить как файл» в Markdown, HTML, TXT, PDF, JSON или CSV. Это удобно для черновиков, технических заметок и дальнейшей ручной редакции. Сохранение запускается пользователем — файлы не создаются автоматически.
