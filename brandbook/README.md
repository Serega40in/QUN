## Направление дизайна

- Глубокий синий, изумрудный, мягкая мята и спокойное золото.
- Премиальная редакционная сетка, крупная типографика, орбиты и органические формы.
- Рисованные фантастические ландшафты и технологические иллюстрации как направление арт-дирекшна.
- Адаптивная вёрстка; страницы содержат стили для печати A4 через браузер.

## Редакционный стандарт

1. Разделять работающие функции, активную разработку и долгосрочную концепцию.
2. Не заявлять неподтверждённые метрики, партнёров, масштабы или финансовые результаты.
3. Не обещать доходность, рост стоимости или ликвидность токенов/NFT.
4. Перед внешним выпуском подтвердить логотип, статусы продуктов, контакты и юридические формулировки.
5. Для типографии сделать отдельный препресс: вылеты, CMYK, разрешение, встроенные шрифты, цветопроба и экспорт PDF/X по требованиям типографии.

## Статус

Это рабочая редакция для развития бренда и переговоров. Веб-страницы — исходники; экспорт из браузера предназначен для предварительного просмотра/печати, но сам по себе не гарантирует соответствие стандарту PDF/X. Финальная журнальная редакция должна включать утверждённые оригинальные арты, проверенные скриншоты продуктов и подтверждённые сведения о команде и финансировании.
