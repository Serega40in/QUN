# QUN Brand & Ecosystem Book

Материалы для презентации экосистемы QUN (редакция 01, октябрь 2026).

- **Журнал / веб-версия:** https://serega40in.github.io/QUN/brandbook/
- **Партнёрский буклет:** https://serega40in.github.io/QUN/brandbook/partner.html
- **Базовый брендбук:** [brand-guidelines.md](brand-guidelines.md)

## Состав
1. Иллюстрированная веб-книга с адаптивной вёрсткой и стилями печати A4.
2. Краткий партнёрский обзор.
3. Рабочие правила бренда, палитра, тон коммуникации и чек-лист препресса.

## Важно
Это первая редакция дизайн-системы и редакционного содержания. Перед внешней рассылкой нужно подтвердить актуальные статусы продуктов, официальный логотип, контактные данные и добавить оригинальные арты/скриншоты. Печать из браузера — пробный экспорт, не типографский PDF/X. Не использовать как финансовую оферту.
