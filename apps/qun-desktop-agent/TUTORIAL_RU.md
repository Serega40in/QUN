# QUN Desktop Agent — туториал для новичка

QUN Desktop Agent — экспериментальная настольная среда: ИИ-чат, встроенный браузер, история диалогов и сохранение результатов. Это открытый прототип, который развивается вместе с QUN.

## 1. Установка из исходников

Требуется Windows 10/11, macOS или Linux и Node.js 20+.

1. Скачайте или клонируйте репозиторий QUN.
2. Откройте терминал в папке `apps/qun-desktop-agent`.
3. Установите зависимости: `npm install`.
4. Проверьте синтаксис: `npm run check`.
5. Запустите приложение: `npm start`.

Для Windows также посмотрите `scripts/install-windows.ps1`. Перед запуском скриптов из исходников просмотрите их содержимое и используйте только официальный репозиторий.

## 2. Подключение ИИ-модели

1. Откройте в боковом меню «Модели и API».
2. В поле API endpoint укажите HTTPS-адрес совместимого Chat Completions API.
3. Введите точный идентификатор модели, который предоставляет выбранный сервис.
4. Если провайдер требует ключ, вставьте его в поле API-ключ и сохраните настройки.
5. Отправьте короткий тестовый запрос.

API-ключ сохраняется через системное защищённое хранилище Electron. Не вставляйте ключи в обычный чат, не публикуйте их в GitHub и не сохраняйте в скриншотах. Условия бесплатного тарифа и лимиты зависят от провайдера; приложение не гарантирует бесплатные или безлимитные запросы.

## 3. Работа с браузером

1. Откройте браузер внутри окна QUN Desktop Agent.
2. Введите HTTPS-адрес в адресную строку и нажмите «Перейти».
3. Откройте нужную страницу.
4. Вернитесь в чат и сформулируйте задачу, например: «Кратко объясни содержание открытой страницы».
5. При необходимости нажмите «Контекст страницы», чтобы явно добавить текст страницы к запросу.

В текущем прототипе модель получает ограниченный текст текущей страницы вместе с запросом. Содержимое сайта считается недоверенными данными: инструкции, найденные на странице, не должны отменять ваши правила.

## 4. Сохранение результата

Под ответом нажмите «Сохранить как файл» и выберите нужный формат: Markdown, HTML, TXT, PDF, JSON или CSV. Сохранение запускается только по вашему выбору.

## 5. Локальная память

Память предназначена для коротких пользовательских заметок и предпочтений. Она сохраняется локально и передаётся в контекст модели при запросе. Это не обучение весов модели. Не помещайте в память пароли, токены, seed-фразы и другие секреты.

## 6. Безопасность и ограничения

- Не запускайте платные API-запросы, если не понимаете тариф и лимиты провайдера.
- Не отправляйте приватные данные внешнему сервису без необходимости.
- Прототип не должен считаться полноценным агентом управления компьютером или гарантированно автономным исполнителем.
- Интеграция QUN Core пока не означает, что очередь команд выполняется end-to-end.
- Перед публикацией, отправкой, покупкой, оплатой или удалением проверяйте действие и его последствия.
- Для реального использования сначала проверьте исходники, зависимости и настройки безопасности.
