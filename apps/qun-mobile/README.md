QUN Mobile — prototype 0.1.0

Open https://serega40in.github.io/QUN/apps/qun-mobile/ on Android over HTTPS, then browser menu → Add to Home screen / Install app.

Current MVP: mobile-first PWA shell, URL/search launcher, QUN shortcuts, service-worker cache and an update button. AI and remote-control screens are placeholders; no provider or remote command channel is connected. Web pages currently open in the phone browser, not in embedded WebView. Native Android build is the next stage for real in-app tabs. Do not put secrets or API keys in public frontend files.
