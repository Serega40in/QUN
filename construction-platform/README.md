# Свой круг — концепт строительной платформы

Демо-страница: https://serega40in.github.io/QUN/construction-platform/

## Идея
Единая точка входа для людей, которые хотят построить дом, выполнить отдельный этап работ или найти специалиста, и для строительных компаний, которым нужны новые обращения.

## Что есть в концепте
- адаптивная главная страница в чистой природной палитре;
- поиск по названию, специализации и описанию;
- фильтры по региону и направлению;
- категории строительных услуг;
- демонстрационные карточки подрядчиков;
- форма-заготовка для заявки.

## Важно
Это интерактивный frontend-прототип. Карточки и цены демонстрационные, форма не отправляет данные на сервер и не хранит их. Для реального запуска нужно подключить базу данных/API, авторизацию, модерацию профилей, загрузку портфолио, обработку заявок и политику персональных данных.

Страница находится в отдельной папке construction-platform/ и не заменяет главную страницу QUN.
