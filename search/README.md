# QUN Search

Статическая адаптивная стартовая страница единого поиска по экосистеме QUN.

## Сейчас
- Поиск по названиям и описаниям разделов в браузере.
- Фильтры по типам разделов.
- Адаптивная мобильная и настольная верстка.
- Без API-ключей и серверных зависимостей.

## Важно
Это MVP-каталог разделов, а не полноценный индекс содержимого всей экосистемы. Для поиска по статьям, товарам, профилям и другим данным нужно подключить соответствующие публичные API/индексы. Ссылки на разделы следует заменить на реальные адреса сервисов по мере их публикации.

## Публикация
Если GitHub Pages включён для репозитория `Serega40in/QUN` с источником, который включает каталог `search/`, страница доступна по адресу `https://serega40in.github.io/QUN/search/`.
